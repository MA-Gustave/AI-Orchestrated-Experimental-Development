# Research thesis, claim boundaries, and contribution

**Publication type:** conceptual argument plus instrumented case study. **Status:** working draft.

## Main question

Can a human operator direct a technically sophisticated experimental software-development process when generative AI performs much of the implementation and candidate preparation, provided that independent tests and recorded evidence govern the decisions?

The question is about the *distribution of work*, not whether natural-language generation has made programming irrelevant. This is a proposal to examine an emerging practical capability, not a finding of universal superiority.

## Three contributions to investigate

1. **Conceptual:** characterize an *automation-driven abstraction shift*, in which the human interface moves from writing low-level instructions toward specifying, orchestrating, and validating systems of technical operations.
2. **Methodological:** describe an inspectable experimental loop with a revisable pattern library, fixed candidate configurations, native test gates, reports and accumulated experimental memory.
3. **Architectural hypothesis:** explore optional workload-profile metadata as an external hint for choosing a specialized JSON parser plan.

## Established ideas not claimed as inventions

- Hierarchical organization and compositionality (Aristotle as analogy, Simon as modern systems theory).
- Human–computer symbiosis and technology for augmenting intellect (Licklider, Engelbart).
- Levels of automation, automation surprises and supervisory burdens (Parasuraman et al., Bainbridge).
- Model-driven engineering, end-user development and program synthesis.
- Algorithm selection, autotuning and evaluator-guided program search (Rice, OpenTuner, FunSearch, AlphaEvolve).

## Levels of support

| The October 2026 E14 benchmark results were recorded. | Project-reported measurements | Independently reproduce on a clean, identified source snapshot. |

| External JSON metadata can improve end-to-end speed. | Not established | Implement, benchmark and account for metadata costs. |
| The 'abstraction shift' is a universal historical law. | Not claimed | Requires a much broader theoretical and empirical treatment. |

## Vocabulary

- **Automation:** delegation of a defined operation to a technical system under explicit conditions.
- **Abstraction boundary:** the interface at which an operator can reason with composed operations without continuously manipulating their internals.
- **Pattern library:** a versioned set of candidate techniques or hypotheses, not an unverified list of performance guarantees.
- **Experimental memory:** dated, inspectable records of attempts, parameters, outcomes and failures, potentially usable by later AI-assisted work.
- **Autonomy:** the degree to which the system acts without a new human decision; do not confuse automated execution with autonomous experiment selection.

## Contributions vs. disclosures

Some internal prompt strategies may remain undisclosed. Claims about the publicly measured software must nevertheless be based on public protocol, source, logs and verifiable results. Do not imply that a hidden optimization routine has been scientifically validated merely because its outputs look promising.
