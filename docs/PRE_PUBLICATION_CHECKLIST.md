# Pre-publication checklist

- [ ] Confirm the formal publishing name, coauthors and acknowledgement policy.
- [ ] Decide on licence terms for original prose and repository assets; preserve source licences for derived code and inherited artwork.
- [ ] Replace the example citation file only after author metadata are correct.
- [ ] Verify all scholarly references against publisher records and primary texts.
- [ ] Audit the manuscript for unsupported historical generalizations or claims that AI has made coding obsolete.
- [ ] Preserve a complete clean source snapshot and hashes for any performance claim; disclose when historical reconstruction is unavailable.
- [ ] Ensure all benchmarks disclose machine, compiler, corpus, experiment design and failures.
- [ ] Explain exploratory vs. confirmatory measurements, selection effects and independent-sample limitations.
- [ ] Clearly label the JSON metadata concept as future research, not an implemented standard.
- [ ] Make the complete manuscript English; remove draft placeholders, incorrect links, keys and personal data.
- [ ] Ensure the `wiki/` mirror and live GitHub Wiki contain matching text.
- [ ] Check your target venue's simultaneous-submission, preprint, blind-review and AI-disclosure rules.
- [ ] Archive a version with a resolvable reference (release, DOI and/or SWHID), as applicable.
