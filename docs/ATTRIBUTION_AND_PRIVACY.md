# Attribution, AI disclosure, and privacy

## Authorship

The public project identity is **Gustave** (Abstract Mechanisms). The final academic author line, any coauthors and ORCID information must be confirmed by the responsible author before publication. AI is an instrument, not an accountable human author. People providing material intellectual or experimental contributions should receive appropriate credit according to the target venue's policies.

## Upstream software and licences

The RVV-VLA implementations derive from simdjson. Acknowledge original simdjson authors, source origins, copyright notices and applicable licence conditions. Do not imply that this manuscript originated the whole JSON parser or that an upstream project has approved the experimental implementation. Distinguish original RVV changes, modifications to existing code, and borrowed techniques.

## Code provenance and historical disputes

Preserve original commits, public links, release records and legitimate communications when documenting priority and provenance. Avoid claims of misconduct or infringement without a file-by-file chronology and evidence. The article's purpose is the research method, not a personal allegation. Consult appropriate expertise if a separate legal/licensing dispute arises.

## AI usage transparency

Describe which work stages involved AI assistance (e.g., candidate code drafting, script writing, report organization) and which stages were validated independently. A plausible AI narrative is not evidence. All outputs must be reviewed for correctness, unsafe operations, attribution and invented citations. Responsibility remains with the human author.

## Confidential workflow

Specific prompts, private operator strategies, credentials, tokens, machine access details and private internal discussions remain unpublished. Never place real SSH information, `.env` files or access keys in this repository. Public benchmarks must not depend on concealed inputs or uncheckable configurations.

## Research integrity

Report failures and regressions. Avoid causal claims about productivity without controlled comparisons. Mark unpublished protocols and unimplemented features as such. Freeze snapshots before an academic or archival release; link immutable identifiers when available.
