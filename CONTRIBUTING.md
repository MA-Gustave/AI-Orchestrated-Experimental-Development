# Contributing to the research documentation

Contributions are welcome when they improve accuracy, provenance, experimental design or clarity. Please open a focused issue or pull request referencing the affected claim and a primary source. Suggestions about the pattern library should ordinarily be filed in [VLA-MethodLab](https://github.com/MA-Gustave/VLA-MethodLab); implementation issues belong to [VectorPath-RVV](https://github.com/MA-Gustave/VectorPath-RVV). This repository handles the interpretation and documentation.

Do not submit private prompts, credentials, unrelated personal accusations or benchmark wins without methods and data. Distinguish first-hand observation from interpretation and proposed future work. All prose is in **English**; conventional historical titles in other languages may be retained as proper titles. Preserve attribution to original software and scholarship.

A useful correction includes: current statement; proposed revision; supporting citation; whether quantitative evidence changes; and any unresolved uncertainty.

These documentation discussions do not constitute submissions of the separate software projects' original reserved additions to simdjson or any other project. For rights and contribution-governance boundaries, read [RESEARCH-GOVERNANCE.md](RESEARCH-GOVERNANCE.md). Do not submit confidential plans or private collaboration information.
