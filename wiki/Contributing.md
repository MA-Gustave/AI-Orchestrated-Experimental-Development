# Contributing and corrections

The best contribution is a well-sourced correction, replication, refutation or constructive experimental proposal. Please open an issue or pull request in the [main research repository](https://github.com/MA-Gustave/AI-Orchestrated-Experimental-Development).

Include the exact statement, source link, proposed improvement and any remaining uncertainty. Mark whether the issue concerns philosophy, prior art, method, raw data, benchmark interpretation or the future JSON metadata concept. Reports of regressions and failed experiments are as welcome as improvements.

Do not post private prompts, SSH data, identifying credentials or unsupported personal allegations. Respect the original simdjson authors' code and licences.

The public author/project identity is **Gustave · Abstract Mechanisms**. This wiki is an English-language documentation resource for a working manuscript, not a peer-reviewed journal.
